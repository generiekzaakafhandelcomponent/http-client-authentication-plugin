This is the Http Client Authentication plugin. It holds the login details GZAC uses for external systems, such as Open Zaak, the Objecten API, Haal Centraal and Suwinet: a token, a key, a username and password, or a client ID and secret, optionally with a certificate. You configure it once under Admin > Plugins and select it in the plugin that talks to the external system. See https://github.com/generiekzaakafhandelcomponent/http-client-authentication-plugin.
