This is the Http Client Authentication plugin. It authenticates the outbound REST and SOAP clients of other plugins with a bearer token, a custom header, an `Authorization: Token` header, Basic credentials, a bearer token with `X-Api-Key`, a ZGW JWT from a client ID and secret, a Keycloak token exchange or a token from a SAML token service, optionally with mutual TLS (PEM or JKS/PKCS12 keystores). It can be selected wherever the ZGW API authentication, `haal-centraal-auth`, `haal-centraal-authentication-plugin`, `suwinet-auth`, `tokenauthentication`, `token-exchange-authentication` or `mTLS-SSLContext` can be selected. See https://github.com/generiekzaakafhandelcomponent/http-client-authentication-plugin.
